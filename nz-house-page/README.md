# Лендинги домов «Новой Земли» для Тильды

Один шаблон (`template.html`) → отдельный лендинг на каждый дом. Дизайн-система «Новая Земля» v1.0:
индиго #261A7E, Alumni Sans + Raleway, стеклянные плашки, кнопки со скруглением 100.

## Откуда берутся данные

`build.py` читает два файла и соединяет их по кадастровому номеру (SKU в CSV = «кадастровый номер» в XLSX):

| Источник | Что берём |
|---|---|
| Выгрузка Tilda Store (CSV) | адрес, цена, площади, готовность, External ID, фото, HTML-описание |
| «Дома в продаже» (XLSX) | статус (в продаже / в резерве), готовность, короткое описание, фото по ссылкам «фото 1…5» |

Описание из CSV раскладывается по разделам автоматически: вступление → «О доме», «Комплектации и цены» → карточки
комплектаций с ценой, «Конструктив / Инженерия / Благоустройство» → вкладки «Как устроен дом», «Условия покупки» → карточки.

```
python3 build.py store.csv houses.xlsx                              # все дома из CSV
python3 build.py store.csv houses.xlsx --only jX2OkV9tzErRmKFLN0S0  # один дом
```

Результат:
- `tilda/<External ID>.html` — код для вставки в Тильду;
- `preview/<External ID>.html` — то же с запасными фото, для просмотра вне Тильды.

## Как вставить в Тильду

1. Создать страницу дома, шапку оставить свою (прозрачную).
2. Добавить блок **T123 «HTML-код»**, вставить содержимое `tilda/<External ID>.html`.
3. Отступ под шапку: в начале стилей `--nzh-header:110px` — подогнать под высоту шапки.
   Если шапка фиксируется при скролле — задать её высоту в `--nzh-sticky-top`, чтобы навигация лендинга не пряталась под ней.
4. Запись на просмотр: кнопки открывают попап `#popup:zapis` (`CONFIG.bookingPopup`).
   В форме попапа завести скрытое поле `house` — туда подставится адрес дома и его External ID.
5. Свои фото и видео — в `CONFIG.extraMedia` (ссылки static.tildacdn.com, встраивание VK/Rutube/YouTube, .mp4).
   Видео на первый экран — `CONFIG.heroVideo`.
6. Карта — `CONFIG.mapSrc` (по умолчанию общий вид посёлка, подставить координаты дома).
7. Ссылку на страницу вписать в карточку товара Tilda Store → «Ссылка на страницу с описанием товара».

`assets/` — фото и иллюстрация из дизайн-системы, используются только в превью.
