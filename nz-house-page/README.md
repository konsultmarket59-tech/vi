# Шаблон страницы дома «Новой Земли»

`house.html` — один шаблон на все дома. Страница берёт данные объекта по «Внешнему коду товара»
(он же код в 1С) и собирает: hero с видео, описание и характеристики, галерею фото/видео,
участок на схеме посёлка, ипотечный калькулятор, запись на просмотр, кнопки «поделиться».

Сейчас данные тестовые и лежат в объекте `HOUSES` внутри файла.

## Как это встаёт в связку 1С → карта → Тильда

1. Сервер карты (dmitpon.website) уже получает объекты из 1С.
2. Добавить на нём:
   - `GET /api/houses/{externalCode}` — JSON в формате записи из `HOUSES`;
   - `GET /house/{externalCode}` — этот шаблон, который подставляет данные из API.
3. Ссылка на страницу строится из кода: `https://dmitpon.website/house/{externalCode}`.
   Её пишем в поле Tilda Store «Ссылка на страницу с описанием товара»
   (руками, CSV-импортом по внешнему коду или скриптом при выгрузке).
4. Заявка на просмотр: форма Тильды или POST на сервер → webhook → бронь в 1С/CRM
   с `externalCode` и номером участка.

Какой дом показать: `?code=<externalCode>` в адресе (на своём сервере) или `#<externalCode>`.

Медиа (`house-orbit-*.mp4/jpg`) в репозиторий не положены — они в опубликованном превью.
