# Шаблон страницы дома «Новой Земли»

`house.html` — один шаблон на все дома, в дизайн-системе «Новая Земля» v1.0
(индиго #261A7E, Alumni Sans + Raleway, стеклянные плашки).

Блоки: hero с ценой и фактами, описание и характеристики, галерея фото/видео,
участок на схеме улицы, ипотечный калькулятор, запись на просмотр, «поделиться», контакты.

## Откуда берутся данные

Страница открывается как `/house/{externalCode}` (или `?code=...`) и запрашивает
`GET https://dmitpon.website/api/houses/{externalCode}` — данные карты, уже синхронизированные с 1С.
Формат ответа — как объект `TEST_HOUSE` в файле. Фото — массив `photos[]` со ссылками из карты.
Если API недоступен, показывается `TEST_HOUSE` с плашкой «Тестовые данные».

## Связка с Тильдой

- Ссылка на страницу строится из «Внешнего кода товара»: `https://dmitpon.website/house/{externalCode}`.
  Её пишем в поле Tilda Store «Ссылка на страницу с описанием товара».
- Заявка на просмотр: POST на webhook → бронь в 1С/CRM с `externalCode` и номером участка.

## Что нужно на сервере карты

1. `GET /api/houses/{externalCode}` — JSON в формате `TEST_HOUSE`.
2. Маршрут `/house/{externalCode}` → отдаёт `house.html`.
3. CORS не нужен, если страница и API на одном домене.

`assets/` — логотип, иллюстрация и фото из дизайн-системы для превью.
