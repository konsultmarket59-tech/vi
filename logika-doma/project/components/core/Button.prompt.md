Main action button — one primary per view (navy), secondary (navy outline) for alternatives, tertiary for "Подробнее →" links.
```jsx
<Button iconRight="chevron-right">Выбрать проект</Button>
<Button variant="secondary">Связаться</Button>
<Button variant="tertiary" iconRight="arrow-right">Подробнее</Button>
<Button loading>Загрузка…</Button>
```
Sizes sm 32 / md 40 / lg 48. Radius 6px. Press = scale .98 + darker navy.
