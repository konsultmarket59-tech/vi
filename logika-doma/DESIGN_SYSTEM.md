# Логика Дома — дизайн-система (полная спецификация)

> Версия 1.0 · октябрь 2026 · основа — брендбук v1.0 (май 2024) и выгрузка Claude Design.
> Исходники: `project/` (токены, компоненты, гайдлайны, UI kit), переписка с дизайн-ассистентом: `chats/chat1.md`.
> Машиночитаемые токены: `tokens.json`. Навык для Claude Code: `.claude/skills/logika-doma-design/SKILL.md` (в корне репозитория).

**Логика Дома** — технологичная платформа для проектирования дома: выбрать проект, настроить его под себя и найти проверенного подрядчика.

- **Слоган:** «Логика решений. Дом вашей мечты.»
- **Позиционирование:** «Технологичная платформа для выбора проектов, настройки и поиска проверенных подрядчиков.»
- **Концепция бренда:** «Технологичная платформа для проектирования дома, подбора проектов и поиска надёжных подрядчиков.»
- **Продукт:** веб-платформа (десктоп + мобильный веб): каталог проектов, страница проекта с конфигуратором, профили подрядчиков. Вторичные носители: обложки соцсетей, презентации, инфографика, баннеры, эскизные проекты (ЭП, PDF A3), скрины с сайта.

## 2. Логотип

### Файлы
| Файл | Что это | Где использовать |
|---|---|---|
| `assets/logo-horizontal.svg` | Основной горизонтальный: знак + «ЛОГИКА / ДОМА» в две строки | Хедер, футер, титул ЭП, документы |
| `assets/logo-horizontal.png` | То же, растр | Где SVG недоступен |
| `assets/logo-vertical.png` | Основной вертикальный: знак сверху, надпись под ним | Квадратные и вертикальные форматы |
| `assets/mark.png` | Только знак (вырезан из логотипа) | Фавикон, иконка приложения, штамп ЭП, аватар |

### Конструкция знака
Прямоугольник в контуре Navy, разделённый на модули: верхний квадрат с диагональным крестом (верхний треугольник заполнен Electric Blue → светлый градиент), нижняя часть — план из прямоугольных модулей, левый нижний модуль залит Technical Cyan, соседний — светло-серым. Знак = «план дома + крыша/конверт», отсылка к сетке и модулям.

Надпись — геометрический гротеск, капс, Navy (`#19317B`/почти чёрный navy), две строки «ЛОГИКА» / «ДОМА».

### Варианты (брендбук)
- **Основной горизонтальный**, **основной вертикальный**, **только знак**, **только логотип (вордмарк)**.
- **Цветовые версии:** на светлом фоне (полноцветный); монохром тёмный; реверс белый на Navy; «на тёмном фоне (акцент)» — белый знак + надпись Cyan на Navy/тёмном.
- **Узкая версия:** знак + «ЛОГИКА ДОМА» в одну строку.
- **Фавикон и иконки:** фавикон 16 px+; иконка приложения 1024×1024; квадратный аватар 512×512; иконка сайта 180×180 (белая подложка, радиус, у варианта сайта — тонкая Cyan-обводка). Иконка приложения/аватар — белый знак на Navy-плашке со скруглением.

### Охранное поле и минимальные размеры
- Охранное поле = высота буквы «Д» со всех сторон.
- Минимум: экран **120 px** по ширине, фавикон **16 px**, печать — **20 мм** (лист 1 брендбука) / **40 мм** (лист 2) — см. §13; используйте 40 мм для горизонтального логотипа, 20 мм — для узкой версии.

### Запрещено
Искажать пропорции · менять цвета · добавлять эффекты (тени, свечения) · поворачивать и наклонять · менять компоновку знака и надписи · нарушать охранное поле · размещать на пёстром фоне.

### В коде
`<Wordmark src="assets/logo-horizontal.svg" height={38}/>` (хедер 38 px, мобильный хедер 28 px, футер 32 px). `inverse` → `filter: brightness(0) invert(1)` для Navy-фона. Без `src` рендерится текстовый вордмарк «ЛОГИКА/ДОМА» (Manrope 700, `height×0.42` px, line-height .95, letter-spacing .06em) — только как запасной вариант. **Никогда не рисовать логотип заново.**

### 4.3 Правила типографики (брендбук)
- Последовательные интерлиньяжи и отступы.
- **Табличные цифры** для цен, размеров и дат (`font-variant-numeric: tabular-nums`).
- Без избыточного трекинга в кириллице.
- Чёткая разница между заголовками и текстом.
- Не более двух шрифтовых семейств.
- Заголовки — sentence case; КАПС только для мелких меток (например «КАК ЭТО РАБОТАЕТ», названия ценностей).
- Цвет заголовков — Navy, текста — Graphite, вторичного — gray-600.
- `text-wrap: balance` для крупных заголовков.

Эталонная пара брендбука: «Технологии для вашего дома» (Manrope Bold, Navy) + «Логика. Проекты. Подрядчики.» (Inter Light/Regular, серый) + короткая Cyan-линия с точкой под ней.

- `--shadow-xs`: `0 1px 2px rgba(25,49,123,.06)`
- `--shadow-card`: `0 2px 8px rgba(25,49,123,.06), 0 1px 2px rgba(25,49,123,.04)`
- `--shadow-hover`: `0 8px 24px rgba(25,49,123,.10)`
- `--shadow-pop`: `0 12px 32px rgba(13,26,69,.14)` (hero-фото, поповеры)

### 5.5 Движение
- `--ease-out: cubic-bezier(.2,.7,.2,1)`, `--dur-fast: 120ms` (цвет, фон, scale), `--dur-base: 200ms` (тень, подъём).
- Hover карточки: `translateY(-2px)` + `--shadow-hover`.
- Press кнопки: `scale(.98)` + более тёмный navy.
- Спиннер: 14 px, обводка 2 px tech-gray, верх Blue, `0.8s linear infinite`.
- Без пружин, параллакса, bounce.

### 5.6 Прозрачность
Только белый 92 % (`rgba(255,255,255,.92)`) — круглая кнопка «избранное» на фото и плашка с логотипом на скринах. Никакого glassmorphism и blur.

## 6. Графический язык

Ключевая идея — **«логика»: сетка → узлы → связи → модули → путь**.

1. **Сетка композиции** — разреженная тонкая квадратная сетка (линии `--grid-line` 1 px, шаг 64 px на сайте; базовый модуль 8). Фон hero и баннеров.
   ```css
   background-image: linear-gradient(var(--grid-line) 1px, transparent 1px),
                     linear-gradient(90deg, var(--grid-line) 1px, transparent 1px);
   background-size: 64px 64px;
   ```
   На Navy: линии `rgba(255,255,255,.07)`.
2. **Узлы** — цветные точки Ø 10 px на пересечениях сетки (центр точно на пересечении: `left = x*64-5`). Типы: активный (Cyan), выбранный (Blue), вторичный (Orange), важный/спец-маркер (Coral), нейтральный/неактивный (Cool Gray; может быть кольцом). На hero ~7 узлов, на баннере 4; не больше одного узла каждого цвета рядом.
3. **Соединения и выбор** — узлы, связанные тонкими линиями (граф).
4. **Модули проекта** — план дома с подсвеченными модулями (полупрозрачная заливка Cyan или Coral + номер 01 / 03).
5. **Линейный путь** — 01 → 02 → 03 → 04 → 05: Идея → Проект → Настройка → Подрядчик → Дом (в инфографике: Идея, Проект, Конфигурация, Подрядчики, Строительство). Компонент `StepPath`.
6. **Модульная матрица / матрица функций** — сетка точек Navy/Cyan/Orange/Coral + галочки, сравнение возможностей.

### Типы линий
| Линия | Стиль |
|---|---|
| Основная связь | Сплошная, Cyan, 1–1.5 px |
| Вторичная связь | Штрих, Navy |
| Вспомогательная | Штрих, Gray |
| Конструкция | Волосяная сплошная, grid gray |

### Фоны
- Почти всегда белый или Soft Background.
- Hero: вертикальный переход `#fff → --surface-soft` поверх сетки с узлами (opacity .7), нижняя граница 1 px.

## 12. Чертежи: планировки, эскизный проект, скрины с сайта
Полный текст правил — `project/guidelines/drawings-rules.md`; карточки — `guidelines/plans/`, `guidelines/eskiz/`, `guidelines/screens/`; исходный ЭП — `guidelines/source/eskiz/page-01…12.jpg`.

### 12.1 Общие правила
- Только Manrope (заголовки, площади, номера) + Inter (подписи, размеры, текст). Никаких моноширинных и узких гротесков.
- Числа: запятая `48,3`; неразрывный пробел перед единицей `48,3 м²`; размеры в мм без единиц `5700`; габариты через `×` `12,22 × 13,32 м`; табличные цифры.
- **Данные сходятся везде** (экспликация = шапка этажа = титул = «Характеристики»). Известные расхождения в исходниках: 1 этаж 109,4 м² (сайт) vs 114,4 м² (ЭП); кабинет 10,9 vs 11,7.
- Конкретные названия помещений (Прихожая, Лестничный холл, Санузел, Постирочная) — никогда «Помещение».
- Navy — заголовки, номера, итоги; Cyan — разделитель «·» и активные узлы; Coral — только ошибки; Green — «в норме».
- Везде бренд «Логика Дома» (не «Свой дом»); имена файлов `logika-doma-…`.

### 12.3 Планировочные решения
- Мокрые зоны (санузел, котельная, сауна, постирочная): заливка + штриховка, подпись «МОКРАЯ ЗОНА» Inter 600 6 pt капс Blue. Двери — дуга открывания 0,25 мм, пунктир. Растения ≤ 1 на помещение.
- **Марка помещения** (RoomTag): узел Ø 4 мм Navy/Blue с номером → название Inter 500 8 pt → площадь Manrope 600 8 pt Navy + габариты Inter 6,5 pt серым. В визуальный центр свободной части комнаты; не перекрывает мебель, линии, размеры. Жёлтые круги-заглушки убрать.
- **Размеры:** линии 0,25 мм `--plan-dim`, засечки 45°; снаружи до 3 цепочек (проёмы → стены/оси → общий габарит, полужирный); шаг 7 мм; текст над линией по центру; подписи не пересекают размерные линии.
- **Шапка и экспликация:** слева сверху «1 этаж · 114,4 м²» (Manrope 700, «·» Cyan), под ней серым — террасы/гараж. Справа сверху — Explication (группы по этажам, итог). Гараж и терраса — вне итога помещений.
- **Ориентация:** север вверх, стрелка «С» справа сверху; масштаб 1:100 для A3.

### 12.4 Эскизный проект (ЭП)
- **Лист:** A3 альбомный 420×297 мм, PDF 300 dpi. Рамка 1,5 px Graphite: слева 20 мм (подшивка), остальные 5 мм. Поля от рамки до объектов ≥ 8 мм. Заголовок листа Manrope 700 14 pt слева сверху. Правая колонка 95 мм — экспликация, ключевые цифры, легенда.
- **Штамп** (TitleBlock, 185×27 мм, вплотную к рамке справа снизу): знак · «Логика Дома · Эскизный проект» · название листа · «Лист N / всего» · дата ММ.ГГГГ.
- **Состав (фиксированный порядок, 12 листов):** 01 Титульный лист · 02 План 1 этажа · 03 План 2 этажа · 04 Схема участка · 05 Разрез 1–1 · 06–09 Фасады (юг, север, восток, запад) · 10–11 Виды · 12 Характеристики и техзадание.
- **Титул:** горизонтальный логотип «Логика Дома» слева сверху (≈ 18 мм высотой); подзаголовок Inter 11 pt («Эскизный проект двухэтажного жилого дома из газобетонных блоков»); **цветной** 3D-вид, скругление 4 мм; внизу три цифры: S общая · S застройки · габариты (Manrope 700 + подпись Inter 7 pt).
- **Планы этажей:** правила 12.3 + в правой колонке крупные цифры Navy («3 Спальни · 2 Санузла · 2 Гардеробные») и площади этажа/общая/террас.
- **Схема участка:** участок светло-зелёный, дом серый со штриховкой, улица — красная линия + «УЛИЦА» капсом. Справа «Отступы по нормам»: ✓ Green «в норме», ✕ Coral «(нужно 2,0)»; нарушения первыми; одинаковые объекты группировать («Клумбы (7) — в норме»).
- **Разрез и фасады:** отметки ▼ ±0,000 / +2,820 справа, Inter 7 pt, через точку; заголовок «Фасад со стороны юга»; реальные цвета отделки; подписи помещений на разрезе Inter 7 pt.
- **Текстовый лист:** H2 Manrope 700 16 pt («Характеристики дома», «В техзадание на расчёт»); пункты Inter 10 pt с «— », интерлиньяж 1,45; цвета отделки HEX капсом + плашка 3×3 мм. Над штампом — Inter Italic 8 pt серым: «Эскизный проект не является рабочей документацией. Конструктивные решения подтверждаются расчётом.»

### 12.5 Скрины с сайта
- **Типы:** 3D-вид (рендер), план этажа, схема участка.
- **Кадр 3D-вида:** дом 55–65 % ширины, горизонт ~2/3 высоты, пустой газон ≤ 30 % кадра; камера ~1,6 м, фронтально или 3/4, без широкоугольных искажений; дом ничем не перекрыт.
- **Оверлеи:** Explication `variant="panel"` в правой колонке ≤ 26 % ширины, отступ 2,5 % от края. Слева снизу — плашка 92 % белого: логотип · «228,7 м² · 2 этажа». Больше ничего поверх кадра.
- **План этажа:** белый фон, обрезка по контуру + 48 px, шапка и экспликация по 12.3, PNG.
- **Форматы:** 1920×1080 (сайт, презентации) · 1080×1350 (соцсети) · 1080×1080 (карточка проекта) · 2480×1754 (план в ЭП). PNG — планы, JPG 85 % — 3D-виды. Имена латиницей: `logika-doma-plan-f1.png`, `logika-doma-view-south.jpg`.
- **Запрещено:** экспликация поверх дома/забора; интерфейс редактора в кадре (курсоры, панели); разные площади на соседних кадрах; ч/б фильтры; водяные знаки по центру.

## 13. Расхождения, допущения и открытые вопросы
1. **Минимальный размер логотипа в печати:** лист 1 брендбука — 20 мм, лист 2 — 40 мм. Нужно решение заказчика.
2. **Навигация хедера:** «Проекты · Подрядчики · Журнал · О сервисе» (лист 1, принято в коде) vs «Проекты · Подрядчики · Услуги · Блог · О нас» (лист 2).
3. **Иконки:** Lucide — временная замена, толще брендовых. Нужен оригинальный набор или решение про `stroke-width: 1.5`.
4. **Изображения:** вырезаны из брендбука в низком разрешении — нужны оригиналы.
5. **Размеры типографики** взяты из верхней части диапазонов брендбука; адаптив для мобильных не задан (предложение: на ширине < 768 px — нижняя граница диапазонов: Display 48, H1 36, H2 28, H3 22, H4 18).
6. **Не из брендбука (предложения ассистента):** терракота для несущих стен, миллиметровые размеры рамки ЭП (20/5/5/5, колонка 95 мм), штамп 185×27 мм, токены `--ld-green`, оттенки navy/gray. Если есть ГОСТ-штамп или корпоративный шаблон — правила нужно подогнать.
7. **Данные проекта:** площади 1 этажа и кабинета не сходятся между сайтом и ЭП (§12.1).
8. Нет исходного кода продукта и Figma — компоненты и экраны реконструированы по брендбуку.
