# Инструменты Figma и их аналоги в пространстве «Фигма»

Пространство «Фигма» — встроенный редактор OpenPencil (MIT) плюс инструменты «Вектора» поверх него
(кнопки «Изображение ▾», «Вектор ▾», ИИ). Обозначения: **✓** — есть, **◐** — упрощённо, **—** — нет.

## Панель инструментов

| Figma | Есть | Где |
|---|---|---|
| Move, Frame, Section | ✓ | редактор |
| Rectangle, Ellipse, Line, Polygon, Star | ✓ | редактор |
| Arrow | ✓ | «Вектор ▾ → Стрелка» |
| Pen, Pencil | ✓ | редактор |
| Text, Hand, Comment | ✓ | редактор |
| Place image (Ctrl+Shift+K) | ✓ | «Изображение ▾ → Поместить изображение…» (и перетаскиванием) |
| Slice, Scale (K) | — | экспорт делается через раздел «Экспорт» у слоя |

## Векторы

| Figma | Есть |
|---|---|
| Режим правки вектора: узлы, ручки, изгиб, сети векторов | ✓ |
| Булевы: объединение, вычитание, пересечение, исключение | ✓ |
| Flatten, Outline stroke, Outline text | ✓ |
| Упростить кривую | ✓ «Вектор ▾ → Упростить кривую» |
| Изображение → вектор с выбором числа цветов | ✓ «В вектор» |
| Paint bucket, скругление отдельных узлов | — |

## Эффекты

| Figma | Есть |
|---|---|
| Drop shadow, Inner shadow, Layer blur, Background blur, режимы наложения | ✓ живые |
| Noise, Texture, Progressive blur, Glass | ◐ «Изображение ▾ → Фильтры и эффекты»: применяются к картинке или запекаются копией слоя поверх |

## Заливки и изображения

| Figma | Есть |
|---|---|
| Сплошная, градиенты (линейный, радиальный, угловой, ромб), несколько заливок, шейдеры | ✓ |
| Изображение: Fill / Fit / Crop / Tile | ✓ |
| Image adjustments: экспозиция, контраст, насыщенность, температура, оттенок, света, тени | ✓ «Изображение ▾ → Коррекция» (картинка в заливке заменяется, отмена — Ctrl+Z) |
| Кадрирование картинки | ✓ «Изображение ▾ → Кадрировать» |
| Удалить фон | ✓ (Polza) |
| Маска (Use as mask) | ◐ |
| Обводка: внутри/по центру/снаружи, пунктир, концы, стрелки | ✓; переменной толщины — нет |

## Макет и прочее

| Figma | Есть |
|---|---|
| Автолейаут, ограничения, сетки | ✓ / ✓ / ◐ |
| Компоненты, экземпляры, варианты | ✓ |
| Переменные, стили | ◐ |
| Прототипирование (переходы между экранами) | ◐ в «Make» — живой интерактивный прототип |
| Экспорт PNG, JPG, WEBP, SVG, PDF, PPTX с масштабом | ✓ |
| Плагины Figma | ✓ из папки (Plugin API) |
| Дизайн-система для ИИ | ✓ ◆ на панели: агенты «Вектора», «Make», «Моушна» следуют ей |
