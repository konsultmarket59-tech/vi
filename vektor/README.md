# Вектор — векторный редактор по образцу CorelDRAW

Векторный графический редактор, который повторяет устройство и приёмы работы CorelDRAW.
Работает в браузере (достаточно открыть `index.html`) и как настольная программа для Windows.

## Как запустить

- **В браузере:** открыть `vektor/index.html` в Chrome, Edge или Яндекс Браузере. Сервер не нужен.
- **Программой для Windows:** запустить workflow **Build Vektor desktop app** во вкладке Actions
  или запушить тег `vektor-build-1`, `vektor-build-2` и т. д. Готовые `.exe` (установщик и portable)
  появятся в релизе `vektor-desktop`.
- **Настольная версия из исходников:** `cd vektor && npm ci && npm start`.

## Как устроено — как в CorelDRAW

| CorelDRAW | Вектор |
|---|---|
| Панель инструментов слева | Указатель, Форма (F10), Масштаб, Панорама, Свободная форма (F5), Безье, Прямоугольник (F6), Эллипс (F7), Многоугольник (Y), Звезда (S), Спираль (A), Текст (F8), Пипетка, Интерактивная заливка (G) |
| Панель свойств сверху | Меняется по инструменту и выделению: X/Y/Ш/В, угол, зеркало, скругление, число углов, шрифт, толщина абриса; без выделения — размер и ориентация страницы |
| Палитра справа | Левая кнопка — заливка, правая — абрис, ✕ — убрать. Без выделения задаёт стиль новых фигур. Внизу — палитра документа |
| Маркеры выделения | Первый щелчок — масштаб (угол — пропорционально, Shift — от центра, Ctrl — шаг 100%), второй щелчок — поворот и наклон с переносимым центром |
| Докеры | Свойства объекта (заливка, абрис, прозрачность, тень, CMYK), Диспетчер объектов (слои, видимость, блокировка, перетаскивание), Выравнивание и распределение, Преобразования (с копиями) |
| Инструмент «Форма» | Узлы и ручки, острые/сглаженные/симметричные, в линию/в кривую, добавить/удалить, разорвать/соединить, замкнуть; скругление углов прямоугольника; сектор/дуга эллипса; острота звезды |
| Упорядочивание | Группа (Ctrl+G), Объединить/Разъединить (Ctrl+L/K), В кривые (Ctrl+Q), порядок (Shift/Ctrl+PgUp/PgDn), выравнивание L R T B E C P |
| Формирование | Сварка, Обрезка, Пересечение, Передний минус задний, Задний минус передний |
| PowerClip | Поместить объекты внутрь фрейма и извлечь обратно |
| Эффекты | Перетекание, тень, прозрачность, линейный и радиальный градиент |
| Вид | Линейки, направляющие (тянуть из линеек), сетка, привязки к сетке, направляющим, объектам и странице, каркасный режим, тёмная тема |

Единицы измерения — миллиметры, кегль — в пунктах. Шаблоны страниц: A0–A6, Letter, визитка, флаер,
форматы соцсетей.

## Файлы

- **Свой формат** `.vkt` (JSON со слоями). Ctrl+S в Chrome сохраняет в тот же файл.
- **Импорт:** SVG (фигуры, кривые, текст, градиенты, `<use>`), PNG, JPG, WEBP. Файлы можно
  перетащить на холст или вставить из буфера обмена.
- **Экспорт:** SVG (размеры в мм, встроенные шрифты), PNG и JPG с выбором разрешения,
  страница / выделенное / все объекты, печать и PDF через окно печати.
- Автосохранение в браузере: после перезапуска открывается последний документ.

Встроенные шрифты из репозитория: DINAMIKA, Oswald, Bebas Neue. Они попадают и в экспорт.

## Чего пока нет

Многостраничные документы, абзацный текст и перевод текста в кривые (нужен разбор файла шрифта),
интерактивные Контур, Оболочка и Выдавливание, живое (редактируемое) перетекание, цветовые профили
и вывод цветоделения. Результат Сварки и Обрезки строится из отрезков, а не из исходных кривых.

## Устройство кода

```
index.html          разметка окна
css/app.css         оформление (светлая и тёмная темы)
js/geom.js          матрицы, кривые Безье, разбор SVG-путей, примитивы, цвет
js/model.js         документ, объекты, габариты, преобразования, отрисовка в SVG
js/app.js           состояние, история (отмена/повтор), вид, привязки, мышь и клавиатура
js/actions.js       команды: группы, порядок, выравнивание, формирование, PowerClip, перетекание
js/tools.js         инструменты панели слева
js/ui.js            меню, панели, докеры, палитра, линейки, диалоги
js/io.js            сохранение, импорт и экспорт
electron/main.cjs   настольная оболочка
vendor/             polygon-clipping (MIT) — для формирования
fonts/fonts.js      встроенные шрифты в base64
```

Масштаб объекта переносится в его геометрию, поэтому толщина абриса и скругления углов
не искажаются при растягивании — так же ведёт себя CorelDRAW.
