# Вектор — CorelDRAW, Фигма, моушн-дизайн и ИИ-агенты в одной программе

Векторный графический редактор по образцу CorelDRAW (читает файлы CorelDRAW любых версий),
встроенный редактор в духе Figma (открывает и сохраняет `.fig`, компоненты, автолейаут, плагины),
моушн-дизайн с экспортом в MP4, генерация цепочками нод и «Make» — прототипы по описанию.
Весь ИИ — только через Polza.ai по вашему ключу, все файлы — на вашем компьютере.

Рабочие пространства переключаются вкладками справа вверху: **Вектор · Фигма · Фото · Моушн · Ноды · Make**.
Один файл можно открыть и довести инструментами разных программ и сохранить в любой формат: CDR нужной версии,
PDF для типографии (CMYK), AI, SVG, PSD, FIG, PNG, JPG, WEBP.

## Как запустить

- **Программой для Windows (рекомендуется):** запустить workflow **Build Vektor desktop app** во вкладке Actions
  или запушить тег `vektor-build-1`, `vektor-build-2` и т. д. Готовые `.exe` (установщик и portable)
  появятся в релизе `vektor-desktop`. Только в настольной версии агент видит папки на диске,
  а CDR сохраняется в нужной версии через установленный CorelDRAW.
- **В браузере:** открыть `vektor/index.html` в Chrome, Edge или Яндекс Браузере (для «Фигмы» нужен
  локальный сервер: `npm run serve`). Запросы к Polza из браузера может заблокировать CORS — надёжнее настольная версия.
- **Настольная версия из исходников:** `cd vektor && npm ci && npm run build:figma && npm start`
  (`build:figma` один раз собирает «Фигму», нужны git и [bun](https://bun.sh)).

## ИИ-агент

Кнопка **✦ Агент** справа вверху. В настройках (⚙) — адрес API (`https://polza.ai/api/v1`), ключ Polza.ai
и модель (подойдёт любая с поддержкой инструментов и картинок: Claude, GPT, Gemini). Ключ хранится только
на компьютере.

Подключение — как в «Личном чате»: если на компьютере есть «Личный чат», при первом запуске «Вектор» сам
берёт оттуда ключ Polza, адрес, модель и настройки прокси (или кнопка «Взять из «Личного чата»» в ⚙).
Все запросы идут через сетевой стек программы: работают системный прокси и VPN, свой прокси с логином и
паролем или прямое подключение; кнопка «Проверить подключение» скажет, что не так.

К задаче прикрепляются **материалы с ролями**:

| Роль | Что прикреплять |
|---|---|
| Исходники | папка с фото и графикой (подпапки тоже) |
| Дизайн-система / брендбук | брендбук в CDR или PDF, папка со шрифтами и логотипами |
| Пример макета | готовая листовка или баннер в CDR, PDF, AI, SVG |
| Прайс / данные | Excel, CSV, Word, TXT с ценами и текстами |
| Папка для результата | куда агент положит готовые файлы |

Примеры задач: «сверстай новую листовку по образцу, тексты такие-то»; «обнови цены в листовке по
прайсу»; «сделай баннеры по шаблону для каждой позиции прайса, заменив цены, фото и текст, сохрани
в PNG»; «перерисуй эту графику в SVG в фирменных цветах».

Что агент умеет делать сам:

- читать файлы из материалов: таблицы Excel (листы целиком), Word, PDF, CDR/VKT/SVG (структура,
  тексты, цвета, шрифты), подключать шрифты из папки;
- смотреть на картинки, страницы брендбуков и примеров и на собственный результат;
- открывать макет-образец, дублировать страницы для серии, менять тексты, цены и фото
  (фото встают в рамку с обрезкой, как PowerClip), подгонять кегль, чтобы текст поместился;
- рисовать фигуры, текст и векторную графику, векторизовать растровые рисунки в заданных
  фирменных цветах, добавлять эффекты;
- сохранять результат в PNG, JPG, SVG, PDF, CDR или VKT — в прикреплённую папку.

Каждое действие агента видно в документе сразу и отменяется (Ctrl+Z или кнопка «Отменить» —
сразу всё задание).

## «Фигма»

Встроенный редактор — открытый [OpenPencil](https://github.com/open-pencil/open-pencil) (лицензия MIT),
собранный внутрь программы с русским интерфейсом:

- открывает и сохраняет файлы Figma `.fig` (и `.pen`), копирование слоёв между программами;
- фреймы, компоненты и варианты, экземпляры, автолейаут и CSS Grid, переменные и стили, страницы,
  векторные инструменты, экспорт PNG/SVG/PDF и в код (JSX/Tailwind), проверка макета;
- **ИИ-чат дизайнера** (100+ инструментов) — автоматически подключён к Polza по ключу и модели из
  настроек агента «Вектора»;
- **плагины Figma**: «Плагины ▾ → Загрузить плагин из папки» — папка с `manifest.json`, кодом и интерфейсом
  запускается через Figma Plugin API (окно плагина, сообщения, хранилище настроек, уведомления);
- **«Из Figma по ссылке»** — забрать кадры любого своего файла из figma.com (нужен личный токен Figma)
  в SVG или PNG — в «Фигму», «Вектор» или «Моушн»;
- кнопки ИИ (Polza): удалить фон, увеличить, перевести в вектор, сгенерировать картинку;
- **«Изображение ▾»** — то, чего нет в самом редакторе: коррекция картинки как в Figma и Lightroom
  (экспозиция, контраст, света, тени, температура, оттенок, насыщенность, сочность, резкость, виньетка,
  зерно, пресеты), фильтры и эффекты (шум, текстура бумаги, прогрессивное размытие, размытие, резкость,
  пикселизация, полутон, постеризация, матовое стекло, ч/б, сепия, инверсия, дуотон), кадрирование
  картинки с пропорциями, удаление фона на месте, «Поместить изображение…»;
- **«Вектор ▾»** — упростить кривую (меньше узлов, сглаживание), стрелки, векторизация с выбором числа цветов;
- обмен: «→ Вектор», «← из Вектора», «→ Моушн»;
- **проекты, как в Figma** («☰ Проект»): проект — папка на компьютере со всеми файлами макетов. Слева —
  файлы с миниатюрами, щелчок открывает файл во вкладке, изменения сами сохраняются в папку каждые 15 с;
  «+ Файл» — новый макет в проекте, «Сохранить» — положить в проект любую открытую вкладку;
- **встроенные плагины** («Плагины ▾»): текст-рыба по-русски, наполнение контентом (имена, телефоны,
  цены, адреса…), стоковые фото в фигуры, стрелки между экранами (как Autoflow), переименование слоёв,
  выделить похожие, найти и заменить, проверка контраста (WCAG, как Stark), палитра из картинки,
  расстановка сеткой, чистка макета, диаграммы.

Полная сверка с Figma — [docs/Figma-инструменты.md](docs/Figma-инструменты.md).

Честно о сообществе Figma: плагины и файлы из каталога сообщества Figma распространяются только внутри
самой Figma. Файлы сообщества открываются здесь после «Save local copy» в Figma (или по ссылке через
токен, если файл скопирован к себе); плагины — те, чей код доступен (на GitHub их тысячи). Часть
Plugin API, завязанная на сервисы Figma (оплата, командные меню, совместные библиотеки команды), не работает.

## «Моушн»

Анимация из своих кадров и графики на фоне цвета, фото или видео с компьютера:

- слои: картинки и кадры (несколько кадров встают по очереди), видео, текст, плашки;
- ключевые кадры (положение, масштаб, поворот, прозрачность, размытие, шторка, печать текста),
  17 готовых анимаций (появление, въезд, выскакивание, шторка, Кен Бёрнс, пульс…) и 8 плавностей;
- таймлайн с перетаскиванием, просмотр, музыка, затемнение и наезд фона;
- экспорт **MP4 (H.264)** и WebM со звуком видео-фона и музыки; проект — файл `.vkm` со всеми ресурсами;
- **ИИ-агент**: сам составляет план анимации и собирает ролик под ключ — из ваших кадров, на фоне
  вашего видео, проверяет кадры глазами, сохраняет MP4 в папку; при необходимости генерирует картинки
  и видео в Polza («Оживить картинку»), вырезает фон.

## «Ноды»

Генерация цепочками: узлы «Текст», «Шаблон», «Картинка/Папка с компьютера», «Выделение из Фигмы»,
«Страница Вектора», «Текстовая модель», «Модель: картинка», «Модель: видео» (любые модели из вашего
Polza), «Удалить фон», «Увеличить», «В вектор», «Сохранить в папку», «Отправить в Вектор/Фигму/Моушн».
Папка на входе запускает цепочку для каждого файла. Готовые шаблоны (фото → новый фон → видео,
пакетное удаление фона и др.), схемы сохраняются в `.vkn`. Оплаченные, но не забранные заказы Polza
остаются в «Незабранных».

## «Make»

Как Figma Make: опишите страницу или приложение — агент напишет HTML/CSS/JS, сам посмотрит результат
(снимок окна просмотра, ошибки консоли), исправит и доведёт. Образцы: дизайн из «Фигмы», картинки,
материалы; просмотр на ширине компьютера, планшета и телефона, правка кода, версии, сохранение в папку
или одним HTML. Код прототипа работает в изолированном окне без доступа к программе и ключу.

## Подготовка к печати

**Макет → Подготовка к печати** (или Файл → Подготовить файл для типографии): выберите требования
типографии — готовые (офсет, цифра, визитки, широкий формат, сувенирка, «только CDR X7») или свои
(название, CMYK/RGB, вылеты, безопасное поле, мин. разрешение картинок, сумма красок, правило чёрного,
текст в кривые, мин. толщина линии, формат и версия файла). Программа проверяет макет и исправляет в один щелчок:

- все цвета → CMYK по профилю (тот же, что у CorelDRAW); точные CMYK, заданные вами, сохраняются как есть;
- чёрный текст и тонкие линии (или весь чёрный) → 100% K, с наложением; крупные чёрные плашки — глубокий
  составной чёрный; сумма красок урезается до лимита;
- фон у края дотягивается на вылеты; текст у края, картинки с низким разрешением, тени — в отчёте;
- текст → кривые, слишком тонкие линии → минимальная толщина.

**«Подготовить и сохранить»** выдаёт PDF в CMYK с вылетами (BleedBox/TrimBox) и метками реза или CDR нужной
версии (точные CMYK передаются в CorelDRAW, картинки переводятся в CMYK). На странице видно: красная
рамка — вылеты, синяя — безопасное поле, зелёные линии — фальцы (Макет → Параметры печати).

**Изменить размер макета** — масштабировать содержимое под новый формат (A4 → A3), вписать или расширить
холст. **Сжать картинки** — до нужного разрешения при их размере в макете (300 dpi для печати, 150 — для экрана)
с качеством, на котором разницы не видно; невидимые части фото в PowerClip обрезаются.

## Фреймы

**Файл → Создать из фрейма**: 70+ заготовок — листовки, визитки, буклеты с фальцами, плакаты, баннеры и
ролл-апы, наклейки с контуром реза, конверты, календари, меню, сувенирка (кружки, футболки, кепки, шопперы,
подушки, коврики, значки, брелоки), соцсети — сразу с вылетами и безопасным полем.
**Запомнить фрейм из файла**: покажите конструктор сувенирного сервиса (CDR, PDF, AI, SVG — например,
футболку) — программа сохранит его размер и контуры отдельным заблокированным слоем. Дальше просто
выбираете фрейм; при сохранении в CDR слой фрейма остаётся в файле в нужном размере.

## «Фото» (как Photoshop и Lightroom)

- Растровый редактор — встроенный [miniPaint](https://github.com/viliusle/miniPaint) (MIT): слои, режимы
  наложения, прозрачность, кисти, ластик, штамп, заливка, градиент, текст, фигуры, выделение, кадрирование,
  фильтры и эффекты, отмена.
- **PSD**: открытие со слоями (маски слоёв применяются к пикселям) и сохранение со слоями.
- **Обработка как в Lightroom**: экспозиция, контраст, светлые/тени, белые/чёрные, матовость, температура и
  оттенок, сочность, насыщенность, чёткость, удаление дымки, резкость, шумоподавление, цвета по каналам
  (тон/насыщенность/яркость), виньетка, зерно, тонирование; «Авто»; 14 пресетов и свои; сравнение «до»;
  пакетная обработка папки. То же — для картинки в «Векторе» (ИИ → Обработка фото).
- ИИ через Polza: удалить фон, увеличить, дорисовать края (генеративное расширение), изменить по описанию.
- Холст: расширить/обрезать или изменить размер. **Сжать до минимума без видимой потери**: программа сама
  подбирает наименьшее качество JPG/WEBP, при котором картинка не отличается от исходной.
- Обмен: «Открыть картинку в «Фото»» из «Вектора» и вернуть обратно, отправить в «Фигму», «Моушн», мокап.

## Конвертер

**Файл → Конвертер файлов**: один или пачка файлов (CDR любой версии, PDF, AI, SVG, FIG, PSD, PNG, JPG, VKT) →
CDR выбранной версии, PDF для типографии, PDF, AI, SVG, PSD (объекты слоями), FIG, PNG, JPG, WEBP, VKT — в папку,
по желанию сразу с подготовкой к печати по требованиям типографии. Те же форматы — в Файл → Экспорт.

## Мокапы (как в Recraft)

**ИИ → Мокап** в «Векторе» (или кнопка «Мокап…» в «Фигме», узел «Мокап» в «Нодах»): любое фото
превращается в мокап, а ваш дизайн ложится на объект и **принимает его форму**.

1. Основа — фото объекта с компьютера, из документа или сгенерированное в Polza (футболка, худи, кружка,
   шопер, коробка, банка, вывеска, экран).
2. Объект — «Найти объект (ИИ)» выделяет его моделью Polza; поправить можно волшебной палочкой, кистью
   и ластиком.
3. Дизайн — файл (PNG, JPG, SVG), выделенное в «Векторе» или в «Фигме»; размер, сдвиг, поворот, узор.
4. Посадка — «по форме объекта» (дизайн повторяет силуэт; рукава, ручки и выступы не мешают),
   «цилиндр» (кружки, бутылки, банки: сжатие к краям и изгиб по дуге) или «плоскость в перспективе»
   (тянете 4 угла). Сетку можно поправить вручную — точки тянутся мышью.
5. Реализм — складки (дизайн смещается по рельефу ткани), тени и блики объекта, режимы печати
   (с тенями, умножение, экран), плотность и мягкость края; «Фотореализм (ИИ)» дорабатывает фактуру
   моделью Polza.

Результат — PNG/JPG, в «Вектор», «Фигму» или «Моушн». Шаблон мокапа (`.vkmock`: фото, объект и посадка)
сохраняется и применяется к серии дизайнов: «Серия дизайнов…» кладёт мокап каждого файла в папку.
Агент «Вектора» тоже умеет делать мокапы (инструмент make_mockup).

## Модели Polza для картинок и видео

«⚙ Polza» в любом пространстве (или ИИ → Модели Polza): модели генерации, правки по референсам,
видео, удаления фона, апскейла и векторизации. Пустое поле — модель подбирается из списка Polza; если
подходящей нет, фон вырезается хромакеем, а векторизация идёт на компьютере. В «Векторе» те же
действия — в меню **ИИ**, и их умеет вызывать агент.

Модель выбирается вручную везде, где работает ИИ: кнопка **▾** рядом с полем модели открывает список
моделей Polza с поиском (можно и вписать название). Список есть в окне «Модели Polza», в каждом
ИИ-диалоге (генерация, правка, дорисовка краёв, видео, векторизация), в узлах «Нодов», у чатов агентов
(«Моушн», «Make») и в шапке агента «Вектора». Перед удалением фона и апскейлом программа показывает,
какой моделью будет работать, — её можно сменить или отключить вопрос галочкой
(ИИ → Спрашивать модель перед запуском).

**Векторизация** (как плагины векторизации в Figma) — окно с живым просмотром: число цветов (2–64),
детализация, сглаживание, удаление фона, фирменная палитра (цвета через запятую), выбор — трассировка на
компьютере или модель Polza. Одинаково в «Векторе», «Фигме» и «Нодах»; настройки запоминаются.

## Файлы CorelDRAW

- **Открытие CDR любой версии** (3 … 2024, включая сжатые и X4+/X6+ контейнеры) — собственным
  разборщиком на основе libcdr (LibreOffice): страницы, группы, фигуры, кривые, заливки (в том числе
  плашечные Pantone/HKS и градиенты), абрисы, текст, растровые изображения. Цвета CMYK переводятся
  тем же профилем, что использует libcdr.
- Файлы CorelDRAW 2017–2025 (формат с потоками страниц и заливками с GUID) читаются собственным
  разборщиком: цвета заливок и абрисов, градиенты, группы, размеры и **имена страниц** — как в Corel.
  Если фигуры лежат на рабочем столе вокруг листа, после открытия показывается весь рисунок.
- **Если в Windows установлен CorelDRAW и файл прочитан не полностью** (не прочитались картинки или
  страницы), он открывается через сам Corel: Corel публикует документ в PDF, а «Вектор» читает его —
  фотографии, PowerClip (обтравка), эффекты и тексты переносятся точно. Файл → «CDR всегда открывать
  через CorelDRAW» включает этот путь для всех файлов. Непрочитанные изображения без Corel помечаются
  серыми заглушками и сообщением.
- **Сохранение**: Ctrl+S для файла из Corel предлагает сохранить обратно в CDR (через Corel), а также в
  формат «Вектора» (.vkt) или PDF для печати. Дальше Ctrl+S сохраняет в выбранный файл и формат.
- **Сохранение в CDR выбранной версии** (11 … 2024): Файл → Экспорт → CDR. Работает в настольной версии
  с установленным CorelDRAW: страницы передаются в Corel и сохраняются в нужной версии. Без Corel
  записать CDR нельзя — формат закрытый; сохраните PDF или SVG, их Corel открывает без потерь.
- Также открываются PDF и AI (как редактируемые кривые, текст и картинки), SVG, PNG, JPG.

## Инструменты как в CorelDRAW

Панель инструментов собрана по группам, как в Corel: правая кнопка мыши или удержание открывает группу,
кнопка показывает последний выбранный инструмент. Помимо фигур, кривых Безье, текста, перетекания,
контура, оболочки, выдавливания и пипеток, есть: свободное выделение, линия по двум точкам, перо,
B-сплайн, ломаная, кривая по трём точкам, умное рисование, художественное оформление (нажим,
каллиграфия), прямоугольник и эллипс по трём точкам, миллиметровка, стандартные фигуры, таблица,
размерные и соединительные линии, кадрирование, нож, ластик, кисти формы (сглаживание, размазывание,
огрубление, вихрь, притяжение, отталкивание), искажение, тень, прозрачность, пипетка цвета, умная заливка.
В меню — недавние файлы, «Закрыть все», «Вернуть к сохранённому», шаблоны, «Собрать для вывода»,
абрис в объект, соединение кривых, упрощение, граница.

**Текст вдоль пути** (Текст → Текст вдоль пути): выделите текст и кривую или фигуру — текст ляжет на контур;
в окне параметров — положение на пути, выключка, расстояние от кривой, другая сторона; «Выпрямить текст»
возвращает обычную строку. В кривые и в PDF текст уходит уже изогнутым.

**Изменить PowerClip**: двойной щелчок по объекту PowerClip (или Объект → PowerClip → Изменить содержимое)
достаёт содержимое из фрейма — его можно двигать, масштабировать, добавлять новые объекты; фрейм показан
пунктиром, кнопка «Готово» собирает PowerClip обратно. Там же — вписать, заполнить, растянуть и выровнять
содержимое по центру фрейма.

Полная сверка с руководством CorelDRAW (что есть, что упрощено, чего пока нет) —
[docs/CorelDRAW-инструменты.md](docs/CorelDRAW-инструменты.md).

## Несколько документов и скорость

- **Вкладки документов** над холстом, как в CorelDRAW, Photoshop и Figma: каждый открытый файл — своя
  вкладка со своей историей отмены, выделением и масштабом. Ctrl+Tab — следующая, Ctrl+W — закрыть
  (с вопросом о сохранении), «+» или Ctrl+N — новый документ. Повторное открытие того же файла
  переключает на его вкладку. Открытые вкладки запоминаются и восстанавливаются при следующем запуске.
- **Большие многостраничные файлы**: холст перерисовывает только изменившиеся объекты, масштаб и
  прокрутка не трогают документ вовсе, большие фото показываются через blob-ссылки (без повторного
  разбора), история отмены хранит неизменённые объекты один раз (тысячи кривых и десятки мегабайт
  фото — без копирования на каждом шаге). Группы в «Диспетчере объектов» свёрнуты, длинные списки
  показываются частями. Автосохранение идёт в фоне в IndexedDB.
- Масштаб колесом и прокрутка не перерисовывают тысячи кривых на каждом шаге: уже нарисованный холст
  сдвигается и масштабируется, а чёткая перерисовка выполняется, когда движение остановилось (как в
  CorelDRAW и Figma). Тонкие абрисы на любом масштабе видны не тоньше пикселя.

## Дизайн-системы

ИИ → «Дизайн-системы…» (или значок ◆ в панели агента, «Make», «Моушн», «Фигме»). Подключается папка
на компьютере — брендбук, гайды (PDF, Word, Markdown, HTML), токены цветов, шрифты, логотипы. Файлы никуда
не копируются и не загружаются: агенты читают их с диска, получают правила, палитру, шрифты и логотипы
и строго им следуют. Шрифты из папки сразу подключаются в редакторе и в просмотре «Make». Можно взять
дизайн-систему из открытого файла «Фигмы» (цвета, шрифты, снимок макета). Кнопка «Что видят агенты»
показывает, какие правила уходят в задание.

**Контекст проекта** — там же, кнопка «+ Контекст: компания, ЦА, прайс»: папка с файлами о компании,
целевой аудитории, прайсом, условиями, отзывами, контактами (Word, PDF, Excel, CSV, тексты). Агенты
сначала читают её, сами составляют смыслы и тексты под задачу и берут цены и условия только оттуда.
Например, в «Make» достаточно написать «страница с условиями покупки дома» — агент прочитает прайс и
условия из папки, напишет контент и сверстает страницу в стиле дизайн-системы.
