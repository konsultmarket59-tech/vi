# Вектор — CorelDRAW, Фигма, моушн-дизайн и ИИ-агенты в одной программе

Векторный графический редактор по образцу CorelDRAW (читает файлы CorelDRAW любых версий),
встроенный редактор в духе Figma (открывает и сохраняет `.fig`, компоненты, автолейаут, плагины),
моушн-дизайн с экспортом в MP4, генерация цепочками нод и «Make» — прототипы по описанию.
Весь ИИ — только через Polza.ai по вашему ключу, все файлы — на вашем компьютере.

Рабочие пространства переключаются вкладками справа вверху: **Вектор · Фигма · Моушн · Ноды · Make**.

## Как запустить

- **Программой для Windows (рекомендуется):** запустить workflow **Build Vektor desktop app** во вкладке Actions
  или запушить тег `vektor-build-1`, `vektor-build-2` и т. д. Готовые `.exe` (установщик и portable)
  появятся в релизе `vektor-desktop`. Только в настольной версии агент видит папки на диске,
  а CDR сохраняется в нужной версии через установленный CorelDRAW.
- **В браузере:** открыть `vektor/index.html` в Chrome, Edge или Яндекс Браузере (для «Фигмы» нужен
  локальный сервер: `npm run serve`). Запросы к Polza из браузера может заблокировать CORS — надёжнее настольная версия.
- **Настольная версия из исходников:** `cd vektor && npm ci && npm run build:figma && npm start`
  (`build:figma` один раз собирает «Фигму», нужны git и [bun](https://bun.sh)).

## ИИ-агент

Кнопка **✦ Агент** справа вверху. В настройках (⚙) — адрес API (`https://polza.ai/api/v1`), ключ Polza.ai
и модель (подойдёт любая с поддержкой инструментов и картинок: Claude, GPT, Gemini). Ключ хранится только
на компьютере.

К задаче прикрепляются **материалы с ролями**:

| Роль | Что прикреплять |
|---|---|
| Исходники | папка с фото и графикой (подпапки тоже) |
| Дизайн-система / брендбук | брендбук в CDR или PDF, папка со шрифтами и логотипами |
| Пример макета | готовая листовка или баннер в CDR, PDF, AI, SVG |
| Прайс / данные | Excel, CSV, Word, TXT с ценами и текстами |
| Папка для результата | куда агент положит готовые файлы |

Примеры задач: «сверстай новую листовку по образцу, тексты такие-то»; «обнови цены в листовке по
прайсу»; «сделай баннеры по шаблону для каждой позиции прайса, заменив цены, фото и текст, сохрани
в PNG»; «перерисуй эту графику в SVG в фирменных цветах».

Что агент умеет делать сам:

- читать файлы из материалов: таблицы Excel (листы целиком), Word, PDF, CDR/VKT/SVG (структура,
  тексты, цвета, шрифты), подключать шрифты из папки;
- смотреть на картинки, страницы брендбуков и примеров и на собственный результат;
- открывать макет-образец, дублировать страницы для серии, менять тексты, цены и фото
  (фото встают в рамку с обрезкой, как PowerClip), подгонять кегль, чтобы текст поместился;
- рисовать фигуры, текст и векторную графику, векторизовать растровые рисунки в заданных
  фирменных цветах, добавлять эффекты;
- сохранять результат в PNG, JPG, SVG, PDF, CDR или VKT — в прикреплённую папку.

Каждое действие агента видно в документе сразу и отменяется (Ctrl+Z или кнопка «Отменить» —
сразу всё задание).

## «Фигма»

Встроенный редактор — открытый [OpenPencil](https://github.com/open-pencil/open-pencil) (лицензия MIT),
собранный внутрь программы с русским интерфейсом:

- открывает и сохраняет файлы Figma `.fig` (и `.pen`), копирование слоёв между программами;
- фреймы, компоненты и варианты, экземпляры, автолейаут и CSS Grid, переменные и стили, страницы,
  векторные инструменты, экспорт PNG/SVG/PDF и в код (JSX/Tailwind), проверка макета;
- **ИИ-чат дизайнера** (100+ инструментов) — автоматически подключён к Polza по ключу и модели из
  настроек агента «Вектора»;
- **плагины Figma**: «Плагины ▾ → Загрузить плагин из папки» — папка с `manifest.json`, кодом и интерфейсом
  запускается через Figma Plugin API (окно плагина, сообщения, хранилище настроек, уведомления);
- **«Из Figma по ссылке»** — забрать кадры любого своего файла из figma.com (нужен личный токен Figma)
  в SVG или PNG — в «Фигму», «Вектор» или «Моушн»;
- кнопки ИИ (Polza): удалить фон, увеличить, перевести в вектор, сгенерировать картинку;
- обмен: «→ Вектор», «← из Вектора», «→ Моушн».

Честно о сообществе Figma: плагины и файлы из каталога сообщества Figma распространяются только внутри
самой Figma. Файлы сообщества открываются здесь после «Save local copy» в Figma (или по ссылке через
токен, если файл скопирован к себе); плагины — те, чей код доступен (на GitHub их тысячи). Часть
Plugin API, завязанная на сервисы Figma (оплата, командные меню, совместные библиотеки команды), не работает.

## «Моушн»

Анимация из своих кадров и графики на фоне цвета, фото или видео с компьютера:

- слои: картинки и кадры (несколько кадров встают по очереди), видео, текст, плашки;
- ключевые кадры (положение, масштаб, поворот, прозрачность, размытие, шторка, печать текста),
  17 готовых анимаций (появление, въезд, выскакивание, шторка, Кен Бёрнс, пульс…) и 8 плавностей;
- таймлайн с перетаскиванием, просмотр, музыка, затемнение и наезд фона;
- экспорт **MP4 (H.264)** и WebM со звуком видео-фона и музыки; проект — файл `.vkm` со всеми ресурсами;
- **ИИ-агент**: сам составляет план анимации и собирает ролик под ключ — из ваших кадров, на фоне
  вашего видео, проверяет кадры глазами, сохраняет MP4 в папку; при необходимости генерирует картинки
  и видео в Polza («Оживить картинку»), вырезает фон.

## «Ноды»

Генерация цепочками: узлы «Текст», «Шаблон», «Картинка/Папка с компьютера», «Выделение из Фигмы»,
«Страница Вектора», «Текстовая модель», «Модель: картинка», «Модель: видео» (любые модели из вашего
Polza), «Удалить фон», «Увеличить», «В вектор», «Сохранить в папку», «Отправить в Вектор/Фигму/Моушн».
Папка на входе запускает цепочку для каждого файла. Готовые шаблоны (фото → новый фон → видео,
пакетное удаление фона и др.), схемы сохраняются в `.vkn`. Оплаченные, но не забранные заказы Polza
остаются в «Незабранных».

## «Make»

Как Figma Make: опишите страницу или приложение — агент напишет HTML/CSS/JS, сам посмотрит результат
(снимок окна просмотра, ошибки консоли), исправит и доведёт. Образцы: дизайн из «Фигмы», картинки,
материалы; просмотр на ширине компьютера, планшета и телефона, правка кода, версии, сохранение в папку
или одним HTML. Код прототипа работает в изолированном окне без доступа к программе и ключу.

## Модели Polza для картинок и видео

«⚙ Polza» в любом пространстве (или ИИ → Модели Polza): модели генерации, правки по референсам,
видео, удаления фона, апскейла и векторизации. Пустое поле — модель подбирается из списка Polza; если
подходящей нет, фон вырезается хромакеем, а векторизация идёт на компьютере. В «Векторе» те же
действия — в меню **ИИ**, и их умеет вызывать агент.

## Файлы CorelDRAW

- **Открытие CDR любой версии** (3 … 2024, включая сжатые и X4+/X6+ контейнеры) — собственным
  разборщиком на основе libcdr (LibreOffice): страницы, группы, фигуры, кривые, заливки (в том числе
  плашечные Pantone/HKS и градиенты), абрисы, текст, растровые изображения. Цвета CMYK переводятся
  тем же профилем, что использует libcdr.
- Если в Windows установлен CorelDRAW, файл, который собственный разборщик не прочитал, Corel
  пересохраняет сам — так открывается всё, что открывает Corel.
- **Сохранение в CDR выбранной версии** (11 … 2024): Файл → Экспорт → CDR. Работает в настольной версии
  с установленным CorelDRAW: страницы передаются в Corel и сохраняются в нужной версии. Без Corel
  записать CDR нельзя — формат закрытый; сохраните PDF или SVG, их Corel открывает без потерь.
- Также открываются PDF и AI (как редактируемые кривые, текст и картинки), SVG, PNG, JPG.

## Как устроено — как в CorelDRAW

| CorelDRAW | Вектор |
|---|---|
| Панель инструментов слева | Указатель, Форма (F10), Масштаб, Панорама, Свободная форма (F5), Безье, Прямоугольник (F6), Эллипс (F7), Многоугольник (Y), Звезда (S), Спираль (A), Текст (F8), Перетекание, Контур, Оболочка, Выдавливание, Пипетка, Интерактивная заливка (G) |
| Панель свойств сверху | Меняется по инструменту и выделению: X/Y/Ш/В, угол, зеркало, скругление, шрифт, выключка, трекинг, параметры эффектов |
| Палитра справа | Левая кнопка — заливка, правая — абрис, ✕ — убрать. Внизу — палитра документа |
| Страницы | Навигатор страниц внизу: добавить, дублировать, переименовать, переставить, удалить; PgUp/PgDn |
| Текст | Щелчок — фигурный текст, рамка — абзацный с переносом и выключкой; перевод текста в кривые |
| Живые эффекты | Контур, Оболочка (с готовыми формами), Выдавливание, Перетекание — перестраиваются при правке исходных объектов; «Разъединить» превращает в обычные объекты |
| Докеры | ИИ-агент, Свойства (CMYK, градиент, абрис, прозрачность, тень, эффекты), Диспетчер объектов (слои), Выравнивание, Преобразования |
| Формирование | Сварка, Обрезка, Пересечение, Передний минус задний, Задний минус передний |
| PowerClip | Поместить объекты внутрь фрейма и извлечь обратно |
| Вид | Линейки, направляющие, сетка, привязки, каркасный режим, тёмная тема |

Шрифты: встроенные (DINAMIKA, Oswald, Bebas Neue), шрифты системы (подключаются автоматически в
настольной версии, в браузере — Текст → Подключить шрифты системы) и загруженные файлы .ttf/.otf.

## Чего пока нет

Текст по кривой, оболочка с произвольными узлами (сейчас — 8 управляющих точек), цветоделение и
профили печати. Чтение CDR проверено на одном реальном файле CorelDRAW X5 — открытых образцов других
версий нет; для сложных файлов в Windows подстрахует установленный CorelDRAW. Сохранение CDR через
Corel собрано по документированной объектной модели CorelDRAW, но в этой среде без Windows и Corel
не запускалось.

```
js/polza.js         Polza: генерация картинок и видео, фон, апскейл, векторизация, общий цикл агента

js/make.js          «Make»: проект, просмотр, агент

electron/           настольная оболочка: файлы, запросы к API, печать в PDF, мост к CorelDRAW,
                    адрес vk://app (модули, видео с диска, запросы к Polza без CORS), снимок окна

                    webm-muxer, html2canvas)
fonts/fonts.js      встроенные шрифты в base64
```
