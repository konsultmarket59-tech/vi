# Конструктор дома — правила работы

- После каждой правки — коммит и пуш в рабочую ветку (`claude/home-design-platform-*`), без напоминаний владельца.
- Релиз собирается сам: пуш в `dom-konstruktor/**` запускает `.github/workflows/release_dom_konstruktor.yml`,
  он обновляет релиз `dom-konstruktor` (одностраничный HTML + архив папки). Проверяйте, что сборка прошла.
- После каждой доработки — обновлять HTML-просмотр (артефакт «Конструктор дома») по той же ссылке.
- Перед пушем: `node --check` всех скриптов и проверка в браузере (Playwright, three.js подменяется локальной копией).
