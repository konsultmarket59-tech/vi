# Дом серии СМАРТ — свободная планировка

Игра-планировщик одноэтажного дома 11 200 × 8 200 мм.

- `tilda-block.html` — код для Тильды. Добавьте на страницу блок **T123 «HTML-код»** и вставьте содержимое файла целиком. Это основной исходник.
- `index.html` — тот же блок, оформленный отдельной страницей. Собирается командой `python3 build.py`, руками не правится.

Нужен интернет: библиотеки загружаются с CDN по очереди (cdnjs → unpkg → jsdelivr). Если один из адресов заблокирован, используется следующий. Все стили блока заключены внутри `#smart-plan` и не задевают остальную страницу. Клавиши работают, только пока курсор находится над блоком.

## Что можно менять

- **Перегородки.** Их можно рисовать, двигать, удлинять, менять толщину (80–150 мм) и удалять. Если сдвинуть стену, примыкающие к ней стены тянутся следом, а двери остаются на своих местах.
- **Внутренние двери.** Ставятся в любую перегородку шириной 600–900 мм. Можно выбрать, в какую сторону открывается дверь и с какой стороны петли.
- **Границы зон.** Пунктирная линия без стены. Делит открытое пространство (кухня, коридор, прихожая), чтобы отдельно считались площади.
- **Мебель.** 28 предметов в каталоге. Их можно перетаскивать, поворачивать (шаг 45°), менять размеры и цвет.
- **Цвет стен.** Палитра из 8 ячеек: готовые наборы или свои цвета. Красить комнаты можно и на плане, и в 3D.

## Что зафиксировано

- Наружные стены, окна и обе входные двери.
- Котельная: стены, габариты, окно, дверь, котёл, бойлер, стиральная и сушильная машины. Внутрь котельной нельзя поставить перегородку или мебель.
- Шахта стояков К1/В1. Сантехнику (унитаз, раковины, ванну, душ, стиральную машину) можно ставить только в голубой зоне у стояков. Внутри этой зоны санузел может быть любой формы.

## Проверка проекта

Справа идёт живой список правил:

- унитаз стоит не дальше 1,8 м от стояка;
- санузел отделён стенами и дверью;
- в каждое помещение можно пройти от входа;
- у спален и гостиной есть окно;
- перегородки не упираются в окна;
- мебель не заходит в стены.

Помещения находятся автоматически, их площади пересчитываются, а названия подставляются по мебели внутри. Любое помещение можно переименовать.

## Библиотеки

- [Konva](https://github.com/konvajs/konva) 9.3.14 — 2D-редактор: перетаскивание, поворот и масштабирование мебели.
- [three.js](https://github.com/mrdoob/three.js) r128 (UMD-сборка) — 3D-вид с тенями и разрезом стен. Управление камерой написано внутри блока.

3D-мебель собрана из простых форм прямо в коде, поэтому внешние модели не нужны. Проект сохраняется в браузере автоматически. Кнопка «Сохранить файл» выгружает его в `.json`, кнопка «Открыть файл» загружает обратно.

## Управление

| Клавиша | Действие |
|---|---|
| V / W / D / Z / P | выбор / стена / дверь / граница зоны / покраска |
| Esc, двойной щелчок | закончить цепочку стен |
| Shift | стена под любым углом |
| R | повернуть мебель на 90° |
| F / H | сменить открывание / петли двери |
| Del | удалить выбранное |
| Ctrl+Z / Ctrl+Shift+Z | отменить / вернуть |
| Ctrl+D | копия предмета |
| Стрелки | сдвиг на 10 мм (с Shift — на 100 мм) |
