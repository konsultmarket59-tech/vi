# Пример выгрузки для ArchiCAD

Проект «Уральский с гаражом 193 м²» из демо-каталога — так выглядит платная выгрузка «Файлы для ArchiCAD» из личного кабинета.

- `primer-proekt.ifc` — модель BIM. В ArchiCAD: «Файл → Открыть», выберите файл, затем «Сохранить как» .pln.
  Внутри: этажи, наружные стены с утеплением и облицовкой, несущие стены, перегородки, окна и двери в проёмах,
  перекрытия, лестница, помещения с названиями и площадями, пристройки — в этом проекте гараж (стены, пол, покрытие); террасы, крыльца и балконы с колоннами выгружаются так же.
  Открывается также в Revit, Renga, BIMcollab Zoom, онлайн-просмотрщиках IFC.
- `primer-proekt.dxf` — чертежи для ArchiCAD, AutoCAD, nanoCAD: каждый этаж на своём листе А3 с рамкой и штампом.
  Слои: стены, утеплитель, перегородки, окна, двери, лестница, марки помещений, экспликация, наружные и внутренние размеры,
  пристройки, координационные оси, марки проёмов — каждый слой включается и выключается.
- `primer-dxf-listy.png` — как выглядят листы DXF.

Проверено: DXF — 0 ошибок (ezdxf audit), IFC — геометрия всех элементов строится (IfcOpenShell).
