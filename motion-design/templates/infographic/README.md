# Infographic Templates

Референсные шаблоны инфографики-flowchart для моушн-пайплайна.
Каждая папка — один вариант: `.eps` — исходный вектор, `preview.jpg` — превью.

| Папка | Шагов | Файл превью |
|---|---|---|
| `3-steps/`   | 3 | `preview.jpg` |
| `4-steps-a/` | 4 | `preview.jpg` |
| `4-steps-b/` | 4 | `preview.jpg` |

## Как это работает в пайплайне

1. Claude вытаскивает из транскрипта 3 или 4 ключевых тезиса.
2. По количеству шагов выбирается шаблон.
3. `.eps` парсится (или заменяется SVG-эквивалентом), геометрия
   перекрашивается в палитру Динамики из `design-system/colors/palette.json`.
4. Каждый шаг появляется в кадре ровно в момент, когда я про него говорю
   (тайминги — из Whisper-транскрипта).

## Добавить свой шаблон

Создай папку `templates/infographic/<имя>/`, положи туда `template.eps`
(или `template.svg`) и `preview.jpg`. Я подхвачу автоматически.
