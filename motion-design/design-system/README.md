# Design System — Динамика

Сюда я загружаю всё, что описывает визуальный язык бренда Динамика.
Скрипты моушн-пайплайна читают эту папку и применяют стиль к каждому видео.

## Что должно лежать здесь

Кладите как есть — распакованные файлы, PDF-гайдлайны, любые форматы.
Ниже — рекомендуемая (не обязательная) раскладка:

```
design-system/
├── logo/
│   ├── logo.svg
│   ├── logo-white.svg
│   └── logo-mark.svg           ← только знак, без надписи
├── colors/
│   └── palette.json            ← { "primary": "#...", ... }
├── typography/
│   ├── fonts/                  ← .ttf / .otf / .woff2
│   └── type-scale.md
├── backgrounds/                ← фоны и паттерны (png/svg/mp4)
├── icons/                      ← иконки для инфографики (svg)
├── motion/                     ← примеры моушн-стиля (mp4/gif)
├── guidelines.pdf              ← брендбук, если есть
└── references/                 ← «как надо» — скриншоты, мудборды
```

## Формат `palette.json`

Если хочешь, чтобы скрипт сразу подхватил цвета — положи файл в таком виде:

```json
{
  "primary":    "#FE3268",
  "secondary":  "#00D4FF",
  "dark":       "#2A2A2A",
  "light":      "#F5F5F5",
  "accent":     "#FFD100"
}
```

Ключи `primary` и `dark` — обязательны, остальное — по желанию.
Если файла нет, я вытяну палитру из логотипа и предложу утвердить.

## Шрифты

Файлы `.ttf` / `.otf` кладите в `typography/fonts/`.
В корне репозитория уже лежит `DINAMIKA-extended.ttf` — если это основной
шрифт, продублируй его сюда или скажи, и я подхвачу оттуда.

## Как это используется

При каждом рендере скрипт:
1. Читает `palette.json` → перекрашивает шаблон инфографики в бренд-цвета.
2. Берёт фон из `backgrounds/` (первый файл или указанный) как подложку.
3. Подставляет `logo/logo-mark.svg` в правый нижний угол (опционально).
4. Использует шрифт из `typography/fonts/` для подписей к шагам.
