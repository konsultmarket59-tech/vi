# Motion Design Automation — Динамика

Автоматизация превращения обычного «говорящего» видео в динамичную видео-инфографику в стиле бренда Динамика.

## Что делает система

На вход — сырое видео (я говорю на камеру).
На выход — ролик, в котором:

1. **Лицо** вырезается по кругу и уплывает вверх-вправо в маленький кружок-«аватарку» (как сториз в Instagram). Внутри круга видео продолжает играть — я продолжаю говорить, а не картинка-заглушка.
2. **Фон** заменяется на брендированный фон Динамики.
3. **Ключевые смысловые моменты** (3–4 шт.) автоматически вытаскиваются из речи и появляются на фоне в виде анимированной инфографики (flowchart из 3 или 4 шагов) — как в шаблонах в `templates/infographic/`.
4. **Синхронизация**: шаги инфографики появляются ровно в тот момент, когда я про них говорю (по таймингу из транскрипта).

## Структура папок

```
motion-design/
├── README.md                    ← этот файл
├── design-system/               ← бренд-ассеты Динамики (я загружаю сюда)
├── source-videos/               ← сюда я кладу сырое видео на обработку
├── templates/
│   └── infographic/             ← референсные шаблоны инфографики
│       ├── 3-steps/             ← 3 шага
│       ├── 4-steps-a/           ← 4 шага, вариант A
│       └── 4-steps-b/           ← 4 шага, вариант B
├── reference-frames/            ← кадры-референсы «как должно выглядеть»
├── scripts/                     ← скрипты автоматизации (пайплайн)
└── output/                      ← готовые ролики
```

## Как пользоваться

### 1. Один раз — залить дизайн-систему

Положить в `design-system/` всё, что определяет визуал Динамики:
логотип, палитра, шрифты, паттерны, референсы. См. `design-system/README.md`.

### 2. На каждое видео

1. Положить `.mp4` в `source-videos/`.
2. Написать мне: «Обработай `source-videos/имя-файла.mp4`».
3. Я:
   - расшифрую речь с таймингами;
   - выделю 3–4 ключевых тезиса;
   - подберу шаблон инфографики (3 или 4 шага);
   - соберу пайплайн: транскрипция → сегментация → tracking лица → маска-круг → анимация круга «вверх» → рендер инфографики поверх фона Динамики → композитинг → цветокор → экспорт;
   - положу готовое в `output/`.

## Пайплайн (технически)

| Шаг | Инструмент | Что делает |
|---|---|---|
| 1. Транскрипт с таймингами | Whisper (large-v3) | получаем `.srt` с точностью до слова |
| 2. Извлечение тезисов | Claude | 3–4 ключевых шага + для каждого — иконка + короткая формулировка (≤ 5 слов) |
| 3. Segmentation лица | MediaPipe Selfie Segmentation / rembg | альфа-маска фона |
| 4. Face tracking | MediaPipe FaceMesh | центр лица покадрово |
| 5. Круг-маска + анимация | ffmpeg + Python | круг с центром на лице, анимация scale+translate из центра в правый верх |
| 6. Фон Динамики | статика/паттерн из `design-system/` | подкладывается под слой с лицом |
| 7. Инфографика | Manim / MoviePy / SVG-анимация | шаблон из `templates/infographic/`, перекрашенный в палитру Динамики, шаги появляются по таймингу |
| 8. Композитинг | ffmpeg | всё сводится в один поток |
| 9. Экспорт | ffmpeg | 1080×1920 (вертикаль) или 1920×1080 (горизонталь) — по флагу |

Скрипты живут в `scripts/`. Первый прогон делаем ручным пайплайном, затем оборачиваем в один `python scripts/motionize.py source-videos/xxx.mp4`.

## Стек

- Python 3.11
- `openai-whisper` или `faster-whisper` (быстрее)
- `mediapipe` (face + segmentation)
- `moviepy`, `ffmpeg-python`
- `Pillow`, `cairosvg` (рендер инфографики)
- `anthropic` (Claude — extraction ключевых тезисов)
