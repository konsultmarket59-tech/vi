# Source Videos

Сюда кладём сырые видео на обработку.

## Как класть

- Формат: `.mp4` (H.264) или `.mov`.
- Ориентация: вертикаль 9:16 или горизонталь 16:9 — оба поддерживаются.
- Длина: до 3 минут за один прогон (дольше — режем на части).
- Звук: обязателен (по нему делается транскрипт и тайминги инфографики).
- Имя файла: `YYYY-MM-DD_короткое-описание.mp4`, например
  `2026-07-25_pro-tarify.mp4`.

## Как запустить обработку

Написать в чат:

> Обработай `source-videos/2026-07-25_pro-tarify.mp4`

Опционально уточнить:
- ориентацию выхода (вертикаль / горизонталь);
- сколько шагов инфографики (3 или 4);
- в какой угол «уплывает» лицо (правый верх по умолчанию);
- нужен ли лого-водяной знак.

Готовое видео появится в `../output/` с тем же именем и суффиксом `_motion.mp4`.

## Ограничения (большие файлы)

GitHub блокирует файлы > 100 МБ. Если видео тяжелее:
- пережми в 1080p / 8 Мбит (`ffmpeg -i in.mp4 -crf 23 -preset medium out.mp4`);
- либо положи в облако и пришли ссылку — я скачаю в контейнер напрямую.

Формально Git LFS тоже подойдёт, но пока не поднимаем — обходимся сжатием.
